# my-portfolio

(주)아이언렌트카 대표 **김기문** 포트폴리오 랜딩 페이지.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 전체 구조 및 내용 |
| `style.css` | 스타일 (차분한 톤 · 모바일 우선 · 다크모드 대응) |

별도의 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 섹션

- 히어로 — 2015년부터 11년차, 대표 소개
- 숫자 — 운영 기간 / 보유 차량 / 팀 규모 / 고객 후기
- 소개 — 지금까지의 이야기
- 경력 — 2015 입문 → 법인 설립 → 700대 운용 → 8인 조직
- 사업 영역 — 신차 장기렌트 · 월렌트 · 사고대차 · 법인렌트
- 일하는 방식 — 대표로서 지키는 세 가지
- 만든 것 — [ironrentcar.com](https://ironrentcar.com), [Iron Team Guide](https://iron-team-guide.vercel.app)
- 연락 — 전화 및 사업자 정보
